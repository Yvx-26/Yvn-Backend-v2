# 测试目录

- `unit/`：基础资料契约、MQTT 转发、Payload、TDR 帧协议和波形转换测试。
- 可靠接收测试使用临时 SQLite 文件、内存关系库和模拟 HTTP/MQTT，不连接真实 Broker，不对业务 MySQL 写入。覆盖落盘后确认、重发去重、重启恢复、失败补偿、慢请求、提交确认丢失和旧位置防覆盖。
- 内存适配不代替真实 MySQL 的锁/并发集成测试；新迁移和真实 Broker 会话仍需在隔离部署验收。
- 后续可增加 `integration/`，连接隔离测试库验证 Webhook、事务和各 API。
- `fixtures/`：重构前合成数据的响应哈希和 SQL 契约快照，覆盖 34 组波形、9 组大屏场景。不包含业务数据库数据；不得为了让重构测试通过而直接重生成快照。
- 分层测试检查纯协议可在无第三方包时导入、接口不执行 SQL、仓储不提交事务、旧导入已移除以及模块无循环依赖。

后续补充测试时，测试库必须与生产库使用不同的 `DB_DATABASE`。

当前全部纯逻辑测试可以直接运行：

```bash
python -m unittest discover -s tests -v
```
